DIARIO DIABETE 0.2.1 - PACCHETTO DI TEST

NON sostituire ancora i file pubblicati su GitHub Pages.
La sincronizzazione deve essere collaudata con dati fittizi in ambiente separato.

Correzioni rispetto alla 0.2.0:
- ricarica lo stato remoto dopo i caricamenti (evita sovrascritture da snapshot obsoleti);
- recupera modificato_il dopo PATCH per mantenere la versione corretta;
- conserva le copie di conflitto localmente senza pubblicarle automaticamente;
- backup JSON comprende anche eliminazioni e copie di conflitto;
- controllo base su importazione di backup meno recenti.

Sicurezza: URL e publishable key nel codice sono pubblici per progetto;
non inserire mai password, secret key o service_role nel codice.
Le regole RLS sono necessarie e vanno verificate prima di caricare dati personali.

VERIFICHE: sintassi JavaScript verificata. Non sono stati effettuati
test end-to-end con il database reale, né test Android.

IMPORTANTE: un conflitto va verificato manualmente prima di considerare
le registrazioni consolidate. La sincronizzazione non sostituisce il backup.
